# Sua vez no terminal

Use o banco criado pelo laboratório. Nenhum exercício precisa alterar os dados.

1. Mostre apenas o nome de todos os lugares, na ordem do cadastro.
2. Mostre o identificador e o nome do lugar cujo `id` é `2`.
3. Mostre os quatro campos de `locais`, ordenando pelo nome. O identificador de cada lugar mudou?
4. Mostre todos os nomes de `pessoas`, em ordem alfabética.
5. A tabela `locais` permite responder quem estava no café? Explique com base nos campos disponíveis.

Compare com [as respostas](respostas.sql) depois de tentar.
